# XSS DOM demo — ASP.NET Core

## Требования
.NET 8 SDK.

## Запуск
В терминале в папке проекта:
```bash
dotnet run
```
Откройте адрес, который покажет терминал.

## Сценарий
1. До атаки оба блока пустые.
2. Вставьте payload со страницы и нажмите «Опубликовать».
3. В уязвимом блоке ввод попадает в HTML через `Html.Raw`.
4. Обработчик `onerror` реально выполняется в браузере и вызывает `document.createElement(...)` и `prepend(...)`.
5. Вверху страницы появляется новый DOM-элемент с текстом «Элемент добавлен JavaScript из пользовательского ввода».
6. Справа тот же ввод отображается как текст: обычный Razor-вывод кодирует HTML, поэтому новый элемент не создаётся.

Главная фраза для demo:
«Я не рисую результат атаки отдельным кодом приложения. Новый элемент действительно создаёт JavaScript, который пришёл вместе с пользовательским вводом».

Это локальная учебная демонстрация; payload не отправляет данные наружу.
